# Video Reference Library

Status: Research needed

## Purpose

Store one verified teaching reference for every class. Videos support instructor preparation. They do not replace the course's teaching method.

## Verification criteria

For every selected video, record:

- Working link
- Teacher or school
- Movement shown
- Style label
- Student level
- Useful timestamp
- Why it supports this class
- Differences from The Tribe's approach
- Safety concerns or unsuitable details
- Date verified
