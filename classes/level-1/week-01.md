# Level 1, Week 1: Your First Kizomba Flow

Status: Draft

## Student-facing promise

Dance a short Kizomba flow while staying grounded and on time.

## Headline movement family

Marca, Basic 1, Basic 2

## Technical foundation

Pulse, posture, full weight transfer

## Prerequisites

- Neutral standing posture
- Pulse recognition
- Complete weight transfer

## Core version

- Marca in place
- Basic 1
- Basic 2

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- Change step size
- Rotate the basic
- Pause and restart on phrase changes

## Entry options

- Enter from neutral standing

## Exit options

- Return to Marca
- Transition to Basic 3 preview

## Social-dance task

Use only Marca, Basic 1, and Basic 2 during one song section. Change movement only after completing the weight transfer.

## Common errors

- Partial weight transfer
- Looking at the feet
- Pulling through the arms

## Safety notes

Keep movement range small. Establish comfortable connection before travelling.
