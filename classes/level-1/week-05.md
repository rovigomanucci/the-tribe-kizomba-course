# Level 1, Week 5: Follower's Saída

Status: Draft

## Student-facing promise

Guide the follower into a clear side pathway while preserving balance.

## Headline movement family

Follower's Saída, lateral walk, simple return

## Technical foundation

Preparation without pulling or pushing

## Prerequisites

- Leader's Saída
- Corridor awareness
- Follower weight recognition

## Core version

- Follower's Saída
- Lateral walk
- Simple return

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- Change number of walks
- Add a rotational exit
- Use a delayed return

## Entry options

- From Basic 3
- From closed walk

## Exit options

- Return to Basic 3
- Enter Vírgula preparation

## Social-dance task

Use the Follower Saída only after a clear preparation. Followers wait for the pathway rather than memorising the sequence.

## Common errors

- Arm-led redirection
- Follower stepping before weight is available
- Leader blocking the corridor

## Safety notes

No forced torso rotation. Keep the follower responsible for their own balance.
