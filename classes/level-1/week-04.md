# Level 1, Week 4: Leader's Saída

Status: Draft

## Student-facing promise

Create a clean leader pathway beside the follower and return without collision.

## Headline movement family

Leader's Saída, corridor position, return to closed hold

## Technical foundation

Lane awareness and independent walking

## Prerequisites

- Basic 3
- Estrela exit
- Clear side step

## Core version

- Leader's Saída
- Corridor walk
- Return to closed hold

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- Forward exit
- Side exit
- Rotational exit

## Entry options

- From Basic 3
- From Estrela

## Exit options

- Return to Basic 3
- Set up follower pathway

## Social-dance task

Use the Leader Saída once per musical phrase, then choose one of two exits.

## Common errors

- Leader stepping into follower line
- Pulling the follower sideways
- Losing timing during return

## Safety notes

Keep feet close to the floor. Do not create space by pushing the follower away.
