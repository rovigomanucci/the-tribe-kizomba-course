# Level 1, Week 6: Vírgula and Retrocesso

Status: Draft

## Student-facing promise

Redirect the partnership and recover into social flow without stopping.

## Headline movement family

Simple Vírgula, Retrocesso, redirection exits

## Technical foundation

Rotation, recovery, and exit selection

## Prerequisites

- Follower's Saída
- Quarter turns
- Stable closed connection

## Core version

- Simple Vírgula
- Retrocesso
- Vírgula into Basic 3

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- 90-degree exit
- 180-degree exit
- Delay the redirection

## Entry options

- From Follower's Saída
- From Estrela

## Exit options

- Return to Basic 3
- Exit into open position preview

## Social-dance task

Choose Vírgula or Retrocesso based on floor space. Recover immediately after any missed lead.

## Common errors

- Twisting a planted knee
- Leader rotating only with arms
- Follower anticipating the exit

## Safety notes

Keep pivots small and controlled. Release unnecessary arm tension.
