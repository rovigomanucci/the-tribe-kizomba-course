# Level 1, Week 7: Pause, Tap, and Play

Status: Draft

## Student-facing promise

Use simple pauses and timing changes without losing connection.

## Headline movement family

Pauses, taps, delayed exits, basic texture

## Technical foundation

Listening, balance, and delayed transfer

## Prerequisites

- Basic 3
- Stable stop
- Clear weight identification

## Core version

- Basic 3 with pause
- Tap and go
- Delayed exit

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- Slow timing
- Quick timing
- Small Tarraxinha texture preview

## Entry options

- From any Level 1 basic

## Exit options

- Continue walking
- Redirect with Vírgula

## Social-dance task

Dance one movement family using two timings. Use pauses only when both partners remain balanced.

## Common errors

- Tapping with weight
- Restarting without preparation
- Adding body movement before balance

## Safety notes

Keep Tarraxinha content optional and small. Avoid forcing hip movement.
