# Level 1, Week 3: The Clockwise Flow

Status: Draft

## Student-facing promise

Rotate the partnership smoothly and exit in a chosen direction.

## Headline movement family

Estrela, clockwise rotation, quarter-turn exit

## Technical foundation

Shared centre and circular navigation

## Prerequisites

- Basic 3
- Stable weight transfer
- Small walking steps

## Core version

- Clockwise Estrela
- Quarter-turn exit

## Progressing version

- Add one prepared entry.
- Add one clear exit.
- Repeat with a new partner and adjust movement size.

## Challenge version

- Change number of steps
- Reverse orientation at the exit
- Add a pause before exit

## Entry options

- From Basic 3
- From Marca

## Exit options

- Return to closed walk
- Open corridor for Leader Saída

## Social-dance task

Use Estrela only when floor space allows. Choose one of two exits rather than repeating a fixed pattern.

## Common errors

- Turning with the arms
- Follower crossing unintentionally
- Large travelling circle

## Safety notes

Keep rotation compact. Protect knees by turning through the feet and body rather than twisting a planted leg.
