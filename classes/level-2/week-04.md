# Level 2, Week 4: Pivots, Hooks, and Rotations

Status: Draft

## Student-facing promise

Connect controlled pivots with leg actions while protecting each partner's axis.

## Headline movement family

Quarter pivot, half pivot, pivot into cross

## Technical foundation

Body-led rotation and individual balance

## Prerequisites

- Stable lift and replace
- Quarter-turn control
- Open-position frame

## Core version

- Quarter pivot
- Half pivot
- Pivot into leg cross

## Progressing version

- Add one prepared entry.
- Add one controlled exit.
- Repeat with a new partner and reduce the movement size.

## Challenge version

- Lift into hook preparation
- Travelling pivot
- Reverse rotational exit

## Entry options

- From leg cross
- From open line

## Exit options

- Return to circle
- Exit to suspension preparation

## Social-dance task

Use one pivot sequence, then return to walking. Change direction only after both partners complete the rotation.

## Common errors

- Twisting a planted foot
- Turning through the arms
- Hooking without free-leg preparation

## Safety notes

No forced hooks. Keep knees aligned with toes. Reduce rotation if the partner loses axis.
