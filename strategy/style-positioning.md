# Style Positioning

Status: Draft

## The Tribe's direction

The Tribe teaches strong Kizomba foundations with a Kizomba Fusion direction.

## Working distinctions

### Traditional Kizomba

Use as the foundation for walking, connection, circular flow, weight transfer, and social-dance communication.

### Semba

Reference for playfulness, rhythm, travel, and some movement ancestry. Do not present Semba as the same dance as Kizomba.

### Kizomba Fusion

Use as the label for combining Kizomba foundations with selected influences, including open connection, timing changes, leg actions, pivots, suspensions, and counterbalances.

### Urban Kiz

Introduce lightly where the movement language becomes more linear, separated, tension-based, stop-driven, or pivot-focused. Name Urban Kiz elements accurately rather than calling them traditional Kizomba.

### Tarraxinha

Use as a controlled body and weight-transfer texture. Avoid treating it as decoration without connection and timing.

## Communication rule

When a class contains several influences, state which part comes from which movement language. This helps students develop style awareness instead of treating every move as interchangeable.
